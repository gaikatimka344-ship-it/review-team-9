# Коммит (commit)

## Определение
Коммит — это сохранёный снимок изменений в репозитории. У каждого коммита есть автор, дата и сообщение, которое объясняет, что изменилось.

## Зачем нужно
Коммиты сохраняют историю проекта: по ним видно, кто, когда и что сделал. Незаметно изменить коммит нельзя, поэтому команда всегда может найти, где появилась ошибка, и вернуться к рабочей версии.

## Пример из нашей работы
В ветке 1-commit-agaev я сделал коммит «Добавлена статья «Коммит» (#1)». Номер #1 в сообщении связывает коммит с задачей, и в задаче видно, какие изменения к ней относятся.

## Где найти на GitHub
Settings → Repository; в Pull Request — вкладка Commits.
